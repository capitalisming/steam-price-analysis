# 🎮 Анализ ценовой динамики игр в Steam

Исследование закономерностей скидок на игры: частота, глубина дисконта по жанрам,
сезонность распродаж, «ценовой якорь» и оптимальное окно покупки.

## 📋 Описание проекта

Проект анализирует ценовую политику игр в Steam и отвечает на вопросы:

1. **Как часто** проходят распродажи для разных жанров?
2. **Насколько глубоко** падают цены и есть ли зависимость от жанра?
3. **Когда** лучше всего покупать игры (сезонность)?
4. **Ценовой якорь** — дают ли дорогие игры бо́льшие скидки?
5. **Как быстро** обесцениваются игры с возрастом?
6. **Оптимальное окно покупки** — какой месяц самый выгодный?
